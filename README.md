## How I Use Them

**Frontend** React and Next.js for most web apps with TypeScript to keep things clean and Tailwind to design fast and I pick up Vue or Nuxt or Angular when a project calls for it

**Backend** Node.js for anything close to the web and FastAPI or Django when there is AI involved or I need to ship fast and Go when performance under load matters and .NET or Spring Boot for bigger systems

**Databases** PostgreSQL for relational data and MongoDB when the shape keeps changing and Redis for caching and MySQL or SQLite for lighter projects

**DevOps** Git and GitHub for code and Docker to keep every service isolated and Postman for testing APIs and Nginx in front of the servers all running on Linux and Ubuntu
