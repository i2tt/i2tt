## About Me

Hey I am a full stack developer who loves building things from scratch until they actually work right from the interface people see all the way to the server and database behind it

I started coding because I wanted to make tools that save me time on stuff I do every day then it turned into a hobby and later into my work I have built Discord bots and tools and store websites and complete backend systems and I always like trying new tech to find what fits each project best instead of sticking to one tool

Right now I work with the Soar team focusing on fast websites and systems that handle heavy load and anything related to automation

## What I Work With

On the frontend I use React and Next.js for most web apps and TypeScript to keep the code clean and safe and Tailwind to design fast and I can also work with Vue and Nuxt and Angular when a project needs them

On the backend I work with Node.js since it fits the web best and FastAPI and Django for AI projects or anything that needs quick development and Golang when I need high performance under heavy load and I also have experience with .NET and Spring Boot for large systems

For databases I rely on PostgreSQL for relational data and MongoDB for flexible data and Redis for caching and MySQL and SQLite for smaller projects

For DevOps I use Git and GitHub to manage code and Docker to run everything in isolated environments and Postman to test APIs and Nginx to manage servers and I work on Linux and Ubuntu every day
